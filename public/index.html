Core Payment Features

💳

Standard Payment

Create a basic order and redirect to the hosted payment page. Supports Cards, UPI, NetBanking, and Wallets.

POST /api/orders
🔗

Payment Link

Generate a shareable payment URL with a 30-minute expiry. Send via SMS, email or WhatsApp.

expiryInMins: 30
🔒

Payment Locking

Control which payment methods are visible. This example hides the WALLET method from the payment page.

payment_filter Dashboard Required
💰

Surcharge

Add a ₹10.00 convenience fee + ₹1.80 GST (18%) on top of the order. Total: ₹511.80.

surcharge_amount Dashboard Required

Advanced Features

🔄

UPI Autopay

Set up a recurring UPI mandate. Customer authorizes via their UPI app. Auto-debit happens on schedule.

mandate_auth: true PA/PG Required
🎯

One-Time Mandate (OTM)

Block ₹500 upfront in the customer's account. Execute the debit once using the Execution API.

otm: true PA/PG Required
🔐

Native OTP

Show OTP input directly on the payment page instead of redirecting to the bank's page. Faster checkout.

native_otp: true PA/PG Required
🪪

CVV-Less Payments

Tokenize the customer's card for future use. Subsequent payments skip the CVV box automatically.

save_to_locker: true KAM Required
